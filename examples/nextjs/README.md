# i18next Phrase In-Context Editor post processor nextjs demo

## How to use the demo

### Install dependencies & run

```bash
yarn
yarn dev
```

New tab in your default browser should open. If that's not the case look into your console for the development server address (by default, it's [http://localhost:3000](http://localhost:3000).

The page will reload if you make edits.
Any nextjs errors will be visible within console.

### Set up with your Phrase trial account

This demo requires a [Phrase](https://phrase.com) trial account. To use this demo:

1. Sign up for a free trial at [https://eu.phrase.com/](https://eu.phrase.com/)
2. After creating your trial account, note your **Account ID** and **Project ID**
3. Update the `projectId` and `accountId` values in the demo configuration to match your trial account credentials

These IDs can be found in your Phrase account settings after you've created a project.

## More information

For more info, please have a look at [i18next Phrase In-Context Editor post processor readme](https://github.com/phrase/i18next-phrase-in-context-editor-post-processor).
